1. PURPOSE

This baseline records the approved final Bug Triage visualization enhancement. 2. APPROVED EXECUTIVE VISUALIZATION LAYOUT

The executive visualization area uses equal two-panel rows:

1. Hours Trend | Planned vs Unplanned Effort
2. Program Distribution | Bug Severity Distribution

Program Distribution retains its existing Tempo logged-hours-by-Program semantics. Planned vs Unplanned Effort retains its existing behavior and has only moved to the Hours Trend row. Account Distribution, Team Utilization, Remaining Demand, and all other dashboard visuals retain their existing calculations and behavior.

3. BUG SEVERITY DISTRIBUTION GOVERNANCE

Title: Bug Severity Distribution
Subtitle: Current operational Bug Triage queue by severity
Form: horizontal bar chart

The chart uses only the latest dedicated `Bug Triage_*` Jira export already used by the Bug Triage table. It counts each distinct nonblank Jira Issue Key once and excludes missing Bug Severity (`-`). It renders the fixed category order Blocker, Critical, Major, Medium, Low, Enhancement. Tooltips state the severity and Number of Bugs. Soft, low-saturation colors are used.

The chart has no Tempo, general-backlog, capacity, Team mapping, prior-snapshot, KPI, calculation, reconciliation, search, table-sort, or global-filter input. It creates no new control or filter and does not alter the Bug Triage Details table or snapshot comparison banner.
