PHASE 2 TEMPORAL MODEL CHANGE
- Week Number has been removed from the dashboard UI.
- Week Number has been removed from user-facing filter state.
- Week Number active filter chips have been removed.
- Week picker events and reset logic have been removed.
- Date Range is now the primary time filter for the dashboard.
- Logged Hours now filter by:
  - Date Range
  - existing business filters such as Team, Assignee, Skill, Account, Account Category, Priority, Target Release, Program, and Release Cycle
- Backlog activity and Delivery Progress activity context now use Tempo Work Date and Date Range rather than a user-selected Week Number.
